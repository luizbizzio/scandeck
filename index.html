Meet the 12 code formats

From factory barcodes to colorful experiments, each format was made to solve a different problem.

QR Code

1994 · Japan

QR Code was created by DENSO engineers in Japan to track car parts faster. Its three large corner squares help a scanner find the code from different angles. QR means Quick Response. It later became popular for tickets, menus and payments.

EXAMPLEIronpass MicroView PNG ↗ Learn more at DENSO ↗

Code 128

1981 · United States

Computer Identics introduced Code 128 to store letters, numbers and symbols in a line of bars. It became useful for shipping labels and inventory. Its name comes from the 128 characters in the ASCII set. A long message makes a very wide barcode.

EXAMPLETap RushView PNG ↗ Learn more at KEYENCE ↗

Codablock F

1989 · Germany

Identcode Systeme developed Codablock to place long data on labels with limited width. Codablock F stacks several Code 128 rows above each other. It has been used in electronics and healthcare, where a normal linear barcode can be too long.

EXAMPLESnakeView PNG ↗ Learn more at Seagull Scientific ↗

DotCode

2009 · AIM standard

DotCode uses separate dots instead of solid square cells. It was designed for fast industrial printing on production lines, including packages and small products. Its standard was published by AIM in 2009. ScanDeck uses those dots to store Neon Dodge.

EXAMPLENeon DodgeView PNG ↗ Learn more at AIDC history ↗

Data Matrix

1987 · United States

Data Matrix was developed by ID Matrix for marking small items. Its L-shaped border helps scanners find the rows and columns. You may see it on electronic parts, medical equipment and product labels. It can store more data than its small size suggests.

EXAMPLECatch 10View PNG ↗ Learn more at KEYENCE ↗

Aztec Code

1995 · United States

Andrew Longacre and Robert Hussey developed Aztec Code at Welch Allyn. The square target at its center looks like an ancient Aztec pyramid from above. It does not need a large white border, which makes it useful on compact tickets and travel passes.

EXAMPLEPattern MemoryView PNG ↗ Learn more at Seagull Scientific ↗

PDF417

1991 · United States

Ynjiun Wang invented PDF417 at Symbol Technologies. It works like many short barcodes stacked into one larger symbol. The name refers to its four bars and spaces across 17 units. The format is widely used on identification cards, tickets and travel documents.

EXAMPLEBrick RushView PNG ↗ Learn more at Telerik ↗

MaxiCode

1992 · United States

UPS introduced MaxiCode for quickly sorting and tracking parcels. It uses hexagonal dots around a circular target, similar to a bullseye. That center helps special sorting equipment locate a moving package. Reading it with a normal phone camera can be difficult.

EXAMPLEPerfect TimingView PNG ↗ Learn more at ActivePDF ↗

Micro QR

1997 · Japan

DENSO created Micro QR as a smaller version of QR Code. It uses only one large corner marker, leaving more room for data in a tiny square. The trade-off is very low capacity. In ScanDeck, Pocket Reflex uses a short program and a shared interpreter.

EXAMPLEPocket ReflexView PNG ↗ Learn more at DENSO ↗

rMQR

2022 · Japan

DENSO introduced rectangular Micro QR, or rMQR, to fit long, narrow spaces such as the edge of a box. It keeps QR-style error correction but changes the shape. This makes it useful when there is little space for a normal square code.

EXAMPLECodebreakerView PNG ↗ Learn more at DENSO ↗

IRIS

Open-source research

IRIS is a modern open-source experiment with a circular design. It places colored data cells in rings around a central target and uses error correction to repair missing information. It is not an established retail barcode standard, and real-camera scanning is still being improved.

EXAMPLEWire CrisisView PNG ↗ Learn more at IRIS project ↗

ChromaQR

Open-source project

ChromaQR was built around a simple question: what if one image could carry three QR Codes? It stores separate data in red, green and blue channels, then combines them into one colorful image. The reader must separate those channels to recover the full message.

What does "the game is in the code" mean?

Six games contain a full HTML game. Five contain complete JavaScript, but ScanDeck supplies the HTML needed to display them. Pocket Reflex is Bytecode: its Micro QR contains the complete instructions, but needs the shared Micro VM interpreter. All three labels describe what the symbol stores, not whether a phone camera can scan it.

Code capacity and camera readability are not the same thing. A large game can fit into a symbol and still be hard for a phone to scan, especially with experimental formats.

Only compatible game codes work. Normal website links and product barcodes are not games. Only open game codes you trust.
