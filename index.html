Games inside codes.

ScanDeck is a small game console in your browser.

Most QR codes open a website. ScanDeck is different. The code contains the game itself. Scan it here, and play.

Experimental IRIS decoding is under active development. For safety, only play game codes from sources you trust. Very large codes may be hard to scan with a phone.

How it works

  1. 01Find a ScanDeck game code.
  2. 02Scan it or upload its image.
  3. 03Play in your browser.

QR Code

More space for bigger games.

Code 128 barcode

Less space, for very small games.

Data Matrix

Compact square codes for tiny HTML games.

Aztec Code

Square codes with a central finder pattern.

PDF417

Rows of bars for larger games.

MaxiCode

Short, self-contained JavaScript.

Micro QR

Tiny instructions executed by a reusable interpreter.

rMQR

Short JavaScript in a rectangular QR.

IRIS

Experimental circular code. Small codes are easier to scan with a camera.

ChromaQR

Three QR code data layers combined in red, green and blue. Requires the ScanDeck RGB reader.

Codablock F

Stacked Code 128 rows. Experimental camera decoding.

DotCode

Matrix code made from individual dots. Experimental camera decoding.

Only compatible game codes work. Regular QR links and product barcodes are not games.
